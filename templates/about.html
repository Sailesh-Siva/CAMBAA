BoneSight

BoneSight is an automated bone age assessment framework designed for pediatric hand X-ray analysis. The system combines YOLOv26-based hand localization, a MaxViT backbone enhanced with Residual CBAM attention, multimodal gender-aware feature fusion, and Support Vector Regression (SVR) for final bone age prediction. To improve interpretability, Eigen-CAM explainability is integrated to highlight the skeletal regions that contribute most significantly to each prediction.

BoneScale

BoneScale is a hybrid bone age assessment framework that combines anatomically derived skeletal measurements with deep learning-based image representations. Anatomical features are extracted through principal-axis geometric analysis of individual bones and carpal pixel-area measurements, while complementary deep features are generated using a MaxViT architecture enhanced with CBAM attention mechanisms. These feature sets are fused into a unified representation and processed using an XGBoost regression model to estimate pediatric bone age in months, enabling accurate assessment across diverse stages of skeletal development.
